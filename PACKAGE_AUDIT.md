# Catalyst Package Audit

## Authority model
- `CLAUDE.md` — Claude Code operating contract.
- `project/` — product intent and constraints.
- `docs/visual/aesthetic_direction.md` — single canonical visual authority.
- `docs/architecture/` — technical architecture/contracts.
- `docs/ROADMAP.md` — reconciled milestone order.
- `state/` — current project continuity and evidence.
- `reference_shaders/` — research library only.
- `archive/` — non-authoritative historical material.

## Presets
### Visual
Vanilla Enhanced; Natural / Realistic; Cinematic.
### Performance
Performance; Balanced; Quality; Ultra; Cinematic.

## Reconciliation checks
- Codex and legacy prompts are archived and not active authorities.
- the retired visual-target summary is archived; it does not compete with the canonical aesthetic direction.
- The reconciled roadmap moves shared environmental state and coupled weather/wetness/snow foundations before high-end voxel GI/RT/PT research. Screen-space GI (internal rendering tiers Low/Medium/High) is core image-quality work, not high-end, and ships earlier (M5) alongside the rest of image quality/presentation.
- Settings and performance documentation use the same eight official preset names.
- Normal Claude sessions load current state plus task-relevant documentation instead of requiring a full documentation reread.
- Milestone completion requires implementation plus evidence, state update, and recoverable checkpoint.

## Validation
Archive integrity was checked after packaging. This document intentionally does not use a broad keyword scan for words such as "high", "low", or "medium" because they can legitimately occur in prose, priority labels, or technical descriptions without defining global presets.
