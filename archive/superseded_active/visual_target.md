# Catalyst Visual Target

## User preference
The user wants Catalyst to be **cinematic, incredible, realistic-looking, atmospheric, polished and visually distinctive**.

## Preferred reference qualities

| Reference | Extract principles from |
|---|---|
| Eclipse | atmosphere, lighting, climate/weather feel, water, environmental integration |
| Bliss | atmospheric mood, cinematic environment, sky/light relationship |
| Kappa | advanced lighting, high-end indirect transport, realism-oriented light response (free pack, full source supplied — fully usable as study material) |
| KappaPT | same lighting/realism direction as Kappa, pursued further (paid pack — public info only: screenshots, videos, documentation; never source, never leaked/paywalled archives) |
| Complementary Unbound | sky/environment polish, atmosphere, broad cinematic readability |
| AstraLex | sky richness, environmental presentation, configurable visual systems |
| Eclipse climate qualities | weather transitions, wetness/snow response, coupled environmental state |

## Catalyst visual rules
1. Use references for principles, not cloning.
2. Prefer physically motivated foundations with artistic controls.
3. Preserve readable blacks and controlled highlights.
4. Avoid neon saturation and excessive bloom.
5. Make atmosphere affect lighting, visibility, sky, fog and clouds coherently.
6. Make water visually continuous from above-water to underwater.
7. Make weather feel like a climate state, not disconnected effects.
8. Moving-camera stability matters more than a perfect still screenshot.
9. The renderer should have its own recognizable identity.
10. Visual improvements must survive regression and performance evaluation.
