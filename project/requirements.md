# Catalyst Product Requirements

## Official user-facing presets

### Visual presets
1. Vanilla Enhanced
2. Natural / Realistic
3. Cinematic

### Performance presets
1. Performance
2. Balanced
3. Quality
4. Ultra
5. Cinematic

Performance presets change computational quality; visual presets change artistic presentation. They are composable and individually overridable.

## Product requirements
- Preserve Minecraft identity, geometry, proportions, and gameplay readability.
- Provide a coherent environmental state model shared by weather, sky, clouds, lighting, atmosphere, wetness, snow, foliage, water, and relevant temporal behavior.
- Provide stable direct lighting, shadows, materials, atmosphere, water, clouds/weather, and temporal behavior before high-end transport is treated as release scope.
- Expose meaningful visual controls through Beginner, Intermediate, and Advanced settings experiences.
- Allow explicit user overrides to take precedence over automatic environmental behavior when technically safe.
- Scale expensive systems intentionally by resolution, sample count, update frequency, reuse, or feature availability.
- Protect readability by default even in Cinematic visual mode.
- Maintain evidence-backed compatibility and performance claims.
