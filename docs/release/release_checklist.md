# Catalyst — Release Checklist

Complete this checklist only with real evidence.

- [ ] Active Minecraft/Iris compatibility target verified.
- [ ] Clean release package produced.
- [ ] Default configuration is release-safe.
- [ ] Debug/profiling artifacts are excluded or clearly separated.
- [ ] Supported rendering paths tested.
- [ ] Visual regression matrix is complete for the release scope.
- [ ] Performance measurements recorded for declared target hardware.
- [ ] Blocking known issues are resolved or explicitly documented.
- [ ] Credits, licenses, provenance, and reference obligations are correct.
- [ ] Documentation matches the shipped implementation and preset model.
- [ ] A recoverable Git release checkpoint/tag exists where Git is available.
