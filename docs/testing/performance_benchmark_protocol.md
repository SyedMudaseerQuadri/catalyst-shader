# Catalyst Performance Benchmark Protocol

Every benchmark should record when available:
- GPU
- CPU
- driver
- Minecraft version
- Iris version
- Catalyst commit/version
- resolution
- render scale
- render distance
- simulation distance where relevant
- scene identifier
- camera path/position
- time of day
- weather
- preset
- feature configuration
- warm-up duration
- measurement duration
- average frame time
- relevant percentile frame times
- VRAM/resource information
- comparison baseline

Never fabricate unavailable measurements.
