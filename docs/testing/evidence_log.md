# Catalyst Evidence Log

## Purpose

This file records objective evidence supporting verification claims.

A requirement may be marked **VERIFIED** only when the corresponding evidence is recorded here or in another explicitly referenced evidence record.

## Status Rules

- **VERIFIED** — actually tested/proven with recorded evidence.
- **PARTIAL** — some acceptance criteria are satisfied, but not all.
- **UNVERIFIED** — evidence has not yet been obtained.
- **BLOCKED** — verification cannot proceed because a required dependency/capability is unavailable.
- **DEFERRED** — intentionally postponed by project scope/governance.

**UNVERIFIED must never be treated as VERIFIED.**
