# Catalyst — Documentation Architecture & Settings UX

## Canonical settings model
Use the model in `docs/architecture/preset_model.md` and `docs/architecture/settings_architecture.md`.

Visual presets: Vanilla Enhanced, Natural / Realistic, Cinematic.
Performance presets: Performance, Balanced, Quality, Ultra, Cinematic.

Do not create a competing global quality tier taxonomy. RT/PT are technical techniques, not preset names.

## UX layers
- Beginner: high-level controls and safe system toggles.
- Intermediate: grouped subsystem controls.
- Advanced: meaningful per-parameter controls with dependency/status indicators.

## Documentation rule
Detailed technical documents are task-loaded on demand. `CLAUDE.md` remains small and is not a second copy of the project specification.
